# Paint-over bases

Each image here is rendered from the game itself (`tools/test/bases.js`), so the building, rooms, lake and angles match
what players see. Give ChatGPT the base image and the prompt below. It keeps the layout and repaints it as finished art.

Start every prompt with this:

> Repaint the attached image as a finished illustration. Keep the composition, camera angle, architecture, room layout,
> furniture placement and colours exactly as they are: same building, same windows, same proportions. Replace the flat
> 3D-render look with a rich, realistic painted style like the original Nancy Drew PC game box art (Her Interactive, early
> 2000s): soft natural light, real materials, subtle film grain. No text, no logos, no watermarks.

Then add the line for that image, and send the finished files back to me as they are. I'll size them and hook them up.
